# System overview

Suva Voice helps families in Sri Lanka check on elderly parents or relatives who live alone or far away.

The elderly person does not install an app for the daily check-in. At the scheduled time Suva Voice calls their normal mobile or landline. The prompt asks them to press 1 if they are okay, 2 if they need assistance, or 3 for an emergency. The answer is stored. Assistance and emergency create alerts and notify the configured contacts and staff. If nobody answers, the call is retried and then recorded as a missed check-in. A missed call is not an emergency.

Family members use the customer app to manage loved ones, schedules, reminders, care orders, payments, and subscriptions. Staff use the admin website to monitor calls, alerts, orders, providers, and reports.

The tagline is Care. Connect. Protect.
