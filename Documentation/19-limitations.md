# Known limitations

- Demo mode does not place a call on a real telephone. Asterisk samples are included and disabled.
- Spoken prompts are English. Sinhala and Tamil are stored as the loved one's preferred language and are not spoken by the Windows voice.
- SMS and email are database rows unless an HTTP provider URL is configured. No message is sent to a real phone.
- Payments succeed, pend, or fail inside the demo gateway. No bank or card is contacted.
- Subscription prices are illustrative so the screens have amounts. They are not a commercial price list.
- The product does not contact public emergency services.
- The admin "today's check-in" count is the number of completed call records today, so extra demo calls can make completed larger than the number of schedules. The family home counts each loved one once.
- Delivery maps and the spending sparkline are status displays, not a live courier GPS feed.
- The customer app is verified in the browser through Expo web. A store build and a device install are not produced here.
- Running the acceptance script adds Acceptance Test Elder until you reseed.
